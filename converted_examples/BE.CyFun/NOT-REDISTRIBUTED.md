# BE.CyFun — measured, not redistributed

The converted bundle and its OSCAL re-export were **removed from this
repository on 2026-11-10**. Rule applied: a converted corpus stays only
where the publisher's own terms clearly allow redistributing an adapted
form; where that is in doubt, the result goes and the code stays.

**Source.** CyberFundamentals Framework 2025, BASIC and ESSENTIAL, as resolved OSCAL catalogues ("Comply0 resolution") — Centre for Cybersecurity Belgium (CCB).

**Why it was removed.** In doubt. No licence statement could be found for the framework's machine-readable form or for the third-party resolution it was converted from (checked 2026-11-10). CCB describes the framework as free to use, which speaks to cost, not to redistribution of an adapted form; its PDFs carry a plain © CCB notice.

**What remains.** The converter (`jascon/scripts/convert_cyfun.py`) and the coverage
report in this directory — source *paths*, counts and conversion rules; it
reproduces no text of the publication.

**The measurement stands.** 218 Requirements · 124 Sets · 4,312 / 4,312 source paths mapped. It was made on the publisher's file
and is reproducible by anyone entitled to that file: obtain it from the
publisher under the publisher's terms, place it at `sources/CyFun 2025 BASIC Resolved.json` and `sources/CyFun 2025 ESSENTIAL Resolved.json`,
and run the converter.
