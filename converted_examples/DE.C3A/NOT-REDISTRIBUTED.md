# DE.C3A — measured, not redistributed

The converted bundle and its OSCAL re-export were **removed from this
repository on 2026-11-10**. Rule applied: a converted corpus stays only
where the publisher's own terms clearly allow redistributing an adapted
form; where that is in doubt, the result goes and the code stays.

**Source.** C3A — Criteria enabling Cloud Computing Autonomy v1.0, OSCAL 1.2.2 edition — Bundesamt für Sicherheit in der Informationstechnik (BSI).

**Why it was removed.** In doubt. No licence statement by the publisher could be found for this file (checked 2026-11-10): it is not part of BSI's CC BY-SA repository *Stand-der-Technik-Bibliothek*, public coverage mentions only a PDF, and bsi.bund.de could not be reached from the review session. If BSI publishes it under an open licence, the bundle can return with a `SOURCE-LICENSE.md` beside it.

**What remains.** The converter (`jascon/scripts/convert_c3a.py`) and the coverage
report in this directory — source *paths*, counts and conversion rules; it
reproduces no text of the publication.

**The measurement stands.** 30 Requirements · 9 Sets · 1,093 / 1,093 source paths mapped. It was made on the publisher's file
and is reproducible by anyone entitled to that file: obtain it from the
publisher under the publisher's terms, place it at `sources/c3a_oscal_catalog.json`,
and run the converter.
