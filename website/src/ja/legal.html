独立性

JASCON は、個人の立場で維持している独立したプロジェクトです。National Institute of Standards and Technology（NIST）、Bundesamt für Sicherheit in der Informationstechnik（BSI）、Australian Signals Directorate（ASD）、Centre for Cybersecurity Belgium（CCB）、Center for Internet Security（CIS）、FedRAMP のいずれとも提携関係になく、これらによる承認や推奨も受けていません。OSCAL は NIST のプロジェクトです。フレームワークや標準の名称はそれぞれの発行者に帰属し、刊行物を識別する目的で使用しています。

このサイトは、データフォーマットと、それを用いて行った実測について説明するものです。法的助言でも監査意見でもありません。第三者の刊行物から取った件数には、取得元のバージョンと日付を記載しています。

プライバシー

このサイトのページは、Cookie を設定せず、アクセス解析を埋め込まず、他のホストから何も読み込みません。フォント、スクリプト、画像は、このサイトから配信されます。

  • サーバーログ。これらのファイルを配信するホストは、配信のためにお使いの IP アドレスを処理し、アクセスログを保持する場合があります。このサイトの発行者は、それらを分析しません。
  • 配色、スタイル、言語。ライトとダークの切り替えボタンを押したとき、スタイルを選んだとき、または言語を選んだときに、その選択がブラウザのローカルストレージに保存されます。送信はされません。言語を選ぶまでは、英語のページから閲覧を始めると、ブラウザの設定にある言語のうちこのサイトが提供している最初の言語でそのページが開きます。該当する言語がなければ英語で開きます。この照合は、ページがブラウザ内で行います。
  • トップページのダイジェストのデモは、ブラウザ内で計算します。入力したテキストはブラウザ内にとどまります。
  • アプリとリーダーは、読み込んだバンドルをブラウザ内（IndexedDB とローカルストレージ）に保持します。何もアップロードされません。
  • 言語モデルによる提案。アプリの 2 つのページは、テキストをモデルのサービスに送信できます。送信するのは、ご自身の API キーを入力した後に限られます。送信する内容は画面に表示され、キーはメモリ上にのみ保持されます。送信先として選んだサービスは、そのテキストを自らの条件に従って処理します。
  • GitHub へのリンクは github.com につながり、そこでは GitHub 独自のプライバシーステートメントが適用されます。
