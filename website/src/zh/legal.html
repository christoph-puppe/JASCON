独立性

JASCON 是一个以个人身份维护的独立项目。它与美国国家标准与技术研究院（National Institute of Standards and Technology，NIST）、德国联邦信息安全办公室（Bundesamt für Sicherheit in der Informationstechnik，BSI）、澳大利亚信号局（Australian Signals Directorate，ASD）、比利时网络安全中心（Centre for Cybersecurity Belgium，CCB）、互联网安全中心（Center for Internet Security，CIS）或 FedRAMP 均无关联，也未获得上述机构的批准或认可。OSCAL 是 NIST 的项目。框架和标准的名称归其发布者所有，本站使用这些名称仅为标识相应的出版物。

本站介绍一种数据格式以及用它进行的测量。本站内容不构成法律建议，也不构成审计意见。取自第三方出版物的计数均注明其所依据的版本和日期。

隐私

本站页面不设置 Cookie，不嵌入任何分析工具，也不从其他主机加载任何内容。字体、脚本和图片均来自本站。

  • 服务器日志。传送这些文件的托管方为此会处理您的 IP 地址，并可能保留访问日志。本站发布者不对这些日志进行分析。
  • 配色方案、样式和语言。当您点击浅色/深色切换按钮、选择样式或选择语言时，您的选择会保存在浏览器的本地存储中，不会被传输。在您选择语言之前，如果访问从某个英文页面开始，该页面会以您浏览器设置中本站提供的第一种语言打开；如果本站不提供其中任何一种语言，则以英文打开。这一比较在您的浏览器中进行。
  • 首页上的摘要演示在您的浏览器中进行计算。您输入的文本只保留在浏览器中。
  • 应用和阅读器将您加载的捆绑包保存在您的浏览器中（IndexedDB 和本地存储），不会上传任何内容。
  • 来自语言模型的建议。应用中有两个页面可以向模型服务发送文本。只有在您输入自己的 API 密钥之后，它们才会这样做；它们会显示所发送的内容，且密钥仅保存在内存中。随后，您所选择的服务将依据其自身条款处理这些文本。
  • 指向 GitHub 的链接会将您带到 github.com，该网站适用其自身的隐私声明。
