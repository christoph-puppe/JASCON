Offene Notation · Apache 2.0

Die Datenschicht für GRC-Engineering

JASCON schreibt Standards, Tailoring, Risiken, Umsetzungen, Prüfungen und Attestierungen als einen einzigen Graphen typisierter, inhaltsadressierter JSON-Objekte. Eine Erklärung zur Anwendbarkeit (SoA) wird zur Berechnung, eine maschinelle Prüfung zu etwas, das eine zweite Partei nachrechnen kann, und eine Signatur lässt sich auch dann noch verifizieren, wenn das Bundle neu verpackt wurde.
