⚙Settings

Settings are kept in this browser (localStorage) and apply to every tool. They hold no secret. A change is saved as you make it.

✧Model access

The app works without a model. A page that offers suggestions calls the service chosen here, with the prompts below, once you type a key on that page. The key is not a setting and is not kept: it is held in memory and has to be typed again after a reload. What a call sends is shown on the page before it is sent.

¶Prompts

Every text the app sends to a model is one of these templates with its placeholders filled. An edit is saved as you type and applies to the next call.

▣Storage

Sets are kept in this browser (IndexedDB "jascon-app"). Deleting a set here removes it from this browser only; an exported bundle is not touched.
