A check has two parts. The collector is code that reports facts and decides nothing. The criteria compare those facts with twelve fixed operators, so anyone can recompute a verdict from a recorded observation. A model may draft both; the kernel rules judge the draft, and you decide what is saved.

The Check type belongs to the 2.0.0 release candidate (drafts/CP-CHECK-1.md); 2.0.0 is not tagged yet. This app cannot run a collector.
