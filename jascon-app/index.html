⤒Load a bundle

Or drop a bundle folder, a ZIP or JSON files anywhere on this page. A bundle with a content-manifest.json replaces the content of the active set; loose files are added to it. An advice pack replaces nothing: it is shown below and added when you confirm. Loading from a URL needs this page to be served over http.

⬡Advice packs

An advice pack is a bundle a vendor publishes: its manifest carries a pack header and its objects are Components with the vendor's recommendations. A pack is added to the active set and never loaded over it. You see what it holds before anything is written, and the vendor's manifest is kept beside the set's own, so the set says which release of which pack came in.

◉Integrity and export

Verify recomputes both SHA-256 digests of every object, the package digest over the bytes and the semantic digest over the canonical form, and compares them with the manifest the bundle came with. Export writes a content manifest for what the set holds now; a set nobody changed leaves with the manifest it came with.
