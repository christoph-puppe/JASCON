⤒Load a bundle

Or drop a bundle folder, a ZIP or JSON files anywhere on this page. A bundle with a content-manifest.json replaces the content of the active set; loose files are added to it. Loading from a URL needs this page to be served over http.

◉Integrity and export

Verify recomputes both SHA-256 digests of every object, the package digest over the bytes and the semantic digest over the canonical form, and compares them with the manifest the bundle came with. Export writes a content manifest for what the set holds now; a set nobody changed leaves with the manifest it came with.
